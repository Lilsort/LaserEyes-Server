# LaserEyes (Server-Side Fabric 1.20.1)

A lightweight server-side Fabric mod for Minecraft 1.20.1 that introduces superhero laser eyes, supersonic flight, and telekinetic entity grabbing **without requiring clients to install any mods**.

---

## 🚀 Features

- **Pure Server-Side:** Compatible with vanilla Minecraft clients.
- **Laser Eyes:** Server-driven raycasting producing red dust particles, block destruction, sound effects, and entity combustion.
- **Flight & Levitation:** Server-side motion controls and state handling.
- **Telekinetic Grab:** Pick up entities, carry them around, and release them on command.
- **Commands & Permissions:** Simple server commands to toggle powers for individual players.

---

## 🛠️ Building

```bash
git clone https://github.com/Lilsort/LaserEyes-Server.git
cd LaserEyes-Server
./gradlew build
```
